This codebase was provided by Jiaoyang Li with minor modifications to enable pybind. This codebase is utilized for a baseline for LNS-PBS in the "Many-to-Many Multi-Agent Pickup and Delivery" paper.


After you installed boost and downloaded the source code, go into the directory of the source code and compile it with CMake:
```shell script
cmake -DCMAKE_BUILD_TYPE=RELEASE .
make
```
